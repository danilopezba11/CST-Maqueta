¿Qué es la ciberseguridad?

La ciberseguridad es el conjunto de medidas que ayudan a proteger sistemas, redes, dispositivos y datos frente a diferentes amenazas digitales.

Actualmente utilizamos internet para estudiar, trabajar, comprar y comunicarnos. Por esta razón es importante proteger nuestra información y utilizar buenas prácticas de seguridad.

¿Qué es el phishing?

El phishing es una técnica utilizada para engañar a las personas con el objetivo de obtener información personal como contraseñas, datos bancarios o accesos a diferentes cuentas.

Una forma común de phishing son los correos electrónicos que aparentan ser enviados por una empresa o servicio conocido y solicitan información personal.

¿Cómo crear una contraseña segura?

Una contraseña segura ayuda a proteger nuestras cuentas y nuestra información personal.

Es recomendable utilizar contraseñas diferentes para cada cuenta y combinar letras, números y caracteres especiales.
